A 4 KB Python chess engine: a 0x88 board with alpha-beta search and quiescence (including check evasions), a transposition table, null-move pruning, late-move reductions and killer move ordering, with a tapered piece-square evaluation and a bishop-pair bonus. It searches to a fixed node budget, so its play is deterministic, and it plays the house gauntlet through the make.fun environment.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
